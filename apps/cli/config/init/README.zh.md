# 初始化模板

[English](README.md) | 中文

机器级初始化模板。每次启动时，`apps/cli` 都会遍历此目录树，并将每个文件复制到 harness home（`$DSH_HOME`）下相同的相对路径，**仅当目标文件不存在时**才执行——现有文件永远不会被覆盖，因此用户编辑和已存储数据都是安全的。该步骤是幂等的，并且在插件树挂载之前运行，因此首次启动时的 `settings.yaml` 基线就是设置提供方读取的内容。

- 模板名称是字面量：此处的 `settings.yaml` 会初始化 `$DSH_HOME/settings.yaml`。
- `README.md` 文件属于文档，永远不会被复制。
- 在此新增文件即为新增机器级基线所需的全部改动；移除文件只影响从未运行过包含该文件的启动的机器。
- 机密值不应出现在这里：模板只声明结构和 API key 的环境变量名，密钥本身保存在环境中。
