# 回归计划与执行记录（模板）

## 怎么用

- **写给谁**：本专家自己（下次回归按它执行与比对），以及评审团的测试与缺陷验收席位、技术席位（他们要用这张表判断「这次变更到底跑没跑、跑的是哪一档、数字能不能比」）。
- **填完存哪**：① 覆盖状态与缺口表、不稳定用例隔离区**追加**进 `tests/regression-suite.md`（`update` 追加、**绝不删除既有条目**）；② 本次回归的完整执行记录存 `production/qa/regression-plan-{{date}}.md`。
- **填的纪律**：只填实测到的值；跑不了、缺工具、分母为 0 一律写 `NOT ASSESSED` 并点名缺什么，**不要空着也不要填 0**；探针的 PASS/FAIL 是判定结论，**不是缺陷等级**。
- 口径见 `references/04-regression-plan.md`（触发矩阵、基线五要素、阈值、覆盖状态、抖动分层）。
