# 证据协议（Evidence Protocol）

本文件是**受理与判定的唯一 home**。判定争议时以本文件为准，不以"感觉"为准。

## 1. 证据五元组

任何「引擎侧发现 / 结论」在被判定前都要能补齐这五项。缺项处置是**硬规则**，不得越级给结论：

| # | 项 | 合格长什么样 | 缺项处置 |
|---|---|---|---|
| 1 | 引擎版本 | 精确到小版本（`4.7.2-stable` 优于「4.x」）；3 与 4 不混 | **整条不可判**。先问提出者或读 `project.godot` / `--version`；拿不到 → 记「证据不足」，不给倾向性结论 |
| 2 | 平台 | 操作系统 + 渲染后端（若涉及渲染）+ 导出目标（若涉及导出） | 标「平台未声明」；跨平台结论降级为「仅在 X 平台成立」 |
| 3 | 复现步骤 | 从空工程开始的可执行序列，含每条命令与参数 | 记「证据不足」，并给出你要求的最小复现骨架 |
| 4 | 最小示例 | 能独立运行的最小工程 / 最小脚本，不含项目私有依赖 | 记「证据不足」；不接受「看这段代码就知道」 |
| 5 | 观测输出 | 原始终端输出、profiler 读数、错误堆栈；含数值时必须带采样方式与样本量 | 记「证据不足」；语法检查 / 逻辑 mock / 合成事件**不算验证** |

**一次只验一条**：一个探针同时验多条主张时，失败无法归因，所有相关条目只能记「证据不足」。

## 2. 三态判定

| 判定 | 成立条件 | 不许出现的写法 |
|---|---|---|
| **成立** | 有可复现证据，且你能说明它**排除了哪些替代解释** | 「应该是」「理论上」 |
| **不成立** | 有反例（最小复现实测不符）**或**可执行的反证路径（命令 + 预期反例） | 「我觉得不对」「这不优雅」 |
| **证据不足** | 五元组缺项、证据不可复现、或结论范围超出证据范围 | 「基本没问题」「大致成立」「先按成立处理」 |

**范围越界也是证据不足**：在 Forward+ 上测出的结论不能直接覆盖 Compatibility；在 Windows 上测出的不能直接覆盖 Web；在 4.6 上测出的不能直接覆盖 4.7。越界时按「仅在 X 成立」处理，并列出需要补测的矩阵。

## 3. 来源等级（写进裁决单的「依据」列）

| 级 | 来源 | 写法示例 |
|---|---|---|
| A | 本机实跑原始输出 | `A: 4.7.2-stable win64，命令 …，输出 …（附探针卡路径）` |
| B | 官方文档当前版本 + 小节 | `B: docs.godotengine.org/en/stable/classes/class_node.html#…（访问 2026-10-09）` |
| C | 上游知识库条目 | `C: godot-skills@d52b934 references/deprecated-apis.md（上游核对 2026-02-12，覆盖 4.6）` |
| D | 推测 | `D: 推测——可能因 X；证伪方法：跑 … 看是否 …` |

**C 级是线索不是公理**：上游库面向 4.6，且 `NOTICE.md` 列了四处已知缺陷。引用 C 级时要标注「需 B 或 A 级复核」，尤其是 C# 章节（该章无不确定性标注）。

**D 级不得单独支撑判定**：D 级只能出现在「优化建议」与「待补证据清单」里。

## 4. 事实 / 推测的写法

- 事实行：`【事实】<断言> —— 依据：<级别 + 来源>`
- 推测行：`【推测】<断言> —— 证伪方法：<命令 + 预期>`
- 两者不得混在同一句里；含「可能 / 大概 / 通常」的行默认是推测。

## 5. 版本与平台声明规范

- 每条判定都带：`Godot <版本> @ <平台>`。版本不明写 `版本未声明（不可判）`。
- 涉及渲染的结论追加渲染后端：Forward+ / Mobile / Compatibility。
- 涉及导出的结论追加导出目标与模板版本（模板与引擎版本不一致本身就是一条「严重」风险）。
- GDExtension 结论追加：编译所用 Godot 版本 + ABI 兼容性提示（跨小版本需重编译）。

## 6. 待补证据清单格式

每条「证据不足」都要能直接变成一条待办：

| 字段 | 内容 |
|---|---|
| 条目编号 | 与裁决单问题表一致 |
| 要谁补 | 提出者 / 实施方 / 你自己（探针） |
| 补什么 | 五元组里缺的那几项 |
| 怎么算补齐 | 可判定的最低标准（例：4.7.2 + win64 上跑通最小复现并贴原始输出） |
| 补齐前结论 | 固定写「证据不足，不作为通过依据」 |
