# @deepseek-ai/dsh-host-lookup-llm

[English](README.md) | 中文

Web 查词覆盖层的模型生成词义解释。Typert 网关上的一个 Remote 端点：`lookupLlm/explain` 翻译选中的词（按脚本检测英译中、中译英），并返回 2-4 句的名词介绍，外加可选 IPA 音标与词性分组。路由来自 `agentDefaultModel` 服务，因此解释跟随部署的默认模型。

调用是一次性的辅助 `llm.stream`（无会话、无工具），以严格 JSON 输出框定，并在返回前逐字段校验。

## 模型体验

### 解释请求

#### 模型看到什么

每次调用一个辅助解释请求：选中的词、检测出的语言方向（按脚本 en→zh 或 zh→en）、可选的一小段周边文本片段，以及严格 JSON 输出指令。调用不带会话历史、不带工具、不带先前轮次。

#### Token 影响

每次 `explain` 调用花费一次模型请求，输出上限 700 token；输入即上面那个小 prompt。

#### KV Cache 影响

无；调用是无历史的全新单轮请求，因此不复用任何会话前缀。

## 已知限制与暂缓事项

- **没有会话上下文** —— 解释由词加一小段周边文本片段生成，而非完整会话；上下文感知变体可以传入更多转录。
- **仅默认模型路由** —— 端点跟随 `agentDefaultModel`；不暴露按会话的路由选择。
