# @deepseek-ai/dsh-client-ui-kb

[English](README.md) | 中文

DeepSeek Harness GUI 的 Web 知识库特性：一个位于 Settings 上方的原生侧栏底部操作，切换经 `kb` Remote 命名空间（`@deepseek-ai/dsh-host-kb`）的准全屏三栏知识库面板。

- **侧栏触发器** —— `sidebar.footer.action` 入口：宽栏内为全宽卡片（图标＋标签＋实时文档计数徽标），56px 窄轨上仅图标，正是外壳渲染「Settings 上方的底部操作」的位置。footer 动作纵向堆叠，因此触发器独占一行，不与相邻的 footer 动作挤在一行。
- **面板** —— `shell.overlay` 入口，三栏布局。左栏导航库的分类轴——带按状态计数的状态智能文件夹（收集箱／已归类／已归档）、支持行内新建／重命名的目录树、带计数的标签索引——以及回收站。中栏以卡片（摘要片段、标签、更新日期）列出文档，按置顶与日期分组（今天／昨天／本周／更早），每张卡片带置顶／移动／删除菜单。右栏阅读并编辑一篇文档：面包屑、标题、可操作元数据条（状态与目录移动走 `kb.moveDoc`，标签 chip 走 `kb.saveDoc`）、Ctrl+S 保存的分屏编辑、可点击的反链面板。回收站模式把右栏换成带恢复／彻底删除的只读预览。
- **搜索** —— 顶部搜索框把 2-gram AND 查询路由到 `kb.search` 并上报总匹配数；Esc 清空并回到浏览。

面板每次打开时经 `kb.refresh` 从磁盘重建引擎索引，头部也有刷新按钮，因此 agent 新增或直接编辑的文件无需重启即可出现。

触发器与面板通过注入的 `hooks` 区共享一个 `KbUiController` 打开状态 store，因此任一侧的切换都会收敛另一侧。所有文案都已本地化（zh/en）；所有颜色都是 DSH 主题 token。

## 模型体验

间接地，经 `kb` Remote 命名空间，面板的每个操作都读写 `$DSH_HOME/kb`（任何工作区之外）的机器全局库，从不触及模型；模型面向的 `kb_*` 工具位于 [`@deepseek-ai/dsh-tool-kb`](../../host/tool-kb) 并拥有任何模型可见的效果，同时本包还向统一的 `@` 引用菜单贡献知识库域（`knowledge-base` 触发来源、`@kb:` appearance 注册，以及两个 `conversation.*.refGlyph` chain 占位）。

#### KV Cache 影响

无。

## 已知限制与暂缓事项

- **没有双链导航** —— `[[links]]` 渲染为纯文本；面板内链接跳转暂缓。
- **没有按目录计数** —— 目录树在按目录计数端点落地前不渲染文档计数。
- **扁平目录选择器** —— 新建与移动到表面使用扁平目录选择而非树；导航树本身就是树视图。
- **没有未保存变更拦截** —— 编辑中离开文档或关闭面板会丢弃草稿。
