# Agent Note: Knowledge-base panel three-column workspace

Status: implemented

[English](2026-08-15-kb-panel-three-column-workspace.md) | 中文

## Problem

第一版知识库面板把动态插件设计一比一移植：一个 1040×680 的弹窗，唯一的分类维度是顶栏四个裸状态 chip。后端其实已经携带了更丰富的词汇——按状态的计数、带计数的标签索引、目录过滤、文档摘要、字段补丁保存与文档移动——但面板一个都没用，于是「库」显得局促扁平，而数据模型本足以支撑一个真正的工作台。

## Decision

面板改为四周留 8px 呼吸边的准全屏三栏工作台：分类轴移入导航栏，阅读区拥有文档头与可操作的元数据。

- **导航栏**：状态智能文件夹（收集箱／已归档／已存档）带 `kb.stats` 的按状态计数；目录树由扁平的 `kb.dirs` 在客户端构建，支持行内新建／重命名（经新的 `kb.createDir`／`kb.renameDir`）；标签索引带 `kb.tags` 计数；回收站作为平级视图。
- **列表栏**：文档卡片（标题、两行摘要、标签 chip、更新日期）按置顶与日期分组；每张卡片带置顶／移动／删除菜单。`kb.list` 置顶优先、更新日期次之，`pinned: true` frontmatter 标记经 `kb.saveDoc.pinned` 写入。
- **阅读栏**：面包屑、文档标题、可操作元数据条（状态与目录移动走 `kb.moveDoc`，标签 chip 走 `kb.saveDoc`）、分屏编辑与 Ctrl+S、可点击的反链面板；回收站模式渲染只读预览与恢复／彻底删除。
- **配置**：归档目录从写死的 `90-归档` 变为网关 `archiveDir` 配置（默认 `90-归档`），加载时对保留根目录校验；`kb.stats.archiveDir` 暴露它，面板因此能提供归档移动。状态推导随之生效，`01-inbox` 与 `00-inbox` 同为收集箱根。
- **目录管理**：`kb.createDir` 经 `.keep` 标记建目录（拒绝保留根）；`kb.renameDir` 重命名目录并递归搬迁其下所有条目、重建索引。纯文本 fs 接口没有字节写入操作，因此含二进制资源（如图片）的目录重命名会响亮失败，而不是半搬迁。
- **回收站保留期**：删除时在 `kb/_meta/trash.json` 记录 ISO 时间戳；网关在加载时及此后每天自动清除超过可配置 `trashRetentionDays`（默认 30，`0` 关闭）的回收站文档，并级联清除仅被其引用的图片。早于注册表存在的条目没有时间戳，永不自动清除；`kb.trash` 每条目上报 `deletedAt`。
- **索引热刷新**：引擎维护惰性内存索引，只感知自己的写入；`kb.refresh` 从磁盘重建索引（空文件是已清除标记，不进入索引），面板每次打开及点击头部刷新按钮时调用它，knowledge-base agent preset 在其基于索引的工具执行前（节流）重扫，因此 agent 新增或直接编辑的文件无需重启即可出现。
- 随重命名工作修复两个既有引擎 bug：`move` 与 `remove` 未从内存索引删除旧路径（移动／删除后的文档仍出现在 `kb.list` 里）。

## Alternatives considered

### 保留弹窗并就地迭代 chip 行

改动最小，但分类轴会增多（状态、目录、标签），chip 行扩展性差；弹窗尺寸也限制长文档的阅读体验。

### Notion 式数据库视图（表格／画廊／看板）

数据模型是「文件 + frontmatter」而非结构化记录，且面板是侧栏旁的表面而非独立应用；三栏导航更贴合该库 Markdown 形态已遵循的 Obsidian/Bear 模式。

### 自动把目录压缩进状态文件夹

目录 → 状态的推导已编码了映射；再叠加一层状态编辑会为「文档住在哪」引入第二事实源。

## Consequences

- 面板偏离 Web GUI 的对话框词汇（它是唯一准全屏表面）；Esc 与遮罩点击仍可关闭，侧栏触发器保持切换对称。
- 目录重命名是文档与文本条目操作：被重命名目录下的二进制资源会让调用失败，目录保持旧名直到资源移除。
- 目录树的文档计数与 `[[链接]]` 导航仍缺失（没有按目录计数端点；链接解析已存在但面板尚不跳转），离开文档时未保存的编辑仍被丢弃。

## Testing

- 引擎测试（`packages/host/kb/tests/core.spec.ts`，基于内存 fs 假件）覆盖：配置化归档目录的状态推导、置顶排序与标记写入、目录新建／重命名（含嵌套搬迁与索引删除），以及移动／删除的索引修复。
- 回收站保留期测试覆盖：时间戳记录与上报、清扫过期条目并级联图片、新鲜与遗留条目幸存、保留期 `0`，以及恢复／彻底删除时注销注册表条目。
- 刷新测试覆盖：外部新增文档出现、外部置空文档消失、外部编辑内容生效，以及磁盘索引重写；面板 spec 覆盖打开时刷新与头部按钮刷新。
- 面板组件测试（`packages/client/ui-kb/tests/kb-panel.client.spec.tsx`）覆盖：三栏渲染、带反链的文档打开、卡片菜单置顶、编辑保存与搜索总数。
